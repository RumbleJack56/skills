# Lessons kept from the retired `adhd` skill

The `adhd` skill was removed when the second-brain skills replaced it. Its eval (iteration 1: 100% of checks with
the skill, 24% without) showed these rules work. They now live in `overwhelm`, `plan` and `capture`.

- **Organize, never execute.** Deciding what to do and doing it are separate jobs.
- **Short replies.** Bullets, no recap, about 12 lines at most.
- **At most 3 priorities visible.** More brings the overwhelm back.
- **End with exactly one `**Next:**` action** that can start in under 5 minutes. No menu.
- **Raw first.** Save the user's words before sorting, so nothing is lost if sorting stops.
- **No guilt.** Missed tasks and broken streaks are normal. Replan from where things are. Never list what was missed.
- **One technique when stuck**, chosen to fit: shrink again, timer with permission to stop, body doubling,
  temptation bundling, change the first step's energy, name the blocker, a small immediate reward.
- **Energy means what a task needs**, not how important it is. Ask for the energy pattern once, then reuse it.
- **A restorative non-task counts as a win** at low energy.
- **Streak only when growing.**
- **Privacy gate.** Make sure private notes are gitignored or in a private repo before writing them.
- **Known bug of the old skill:** `focus.md` pointed to a `today.md` that overwhelm mode never created.
  The new `overwhelm` skill creates `today.md` itself.
