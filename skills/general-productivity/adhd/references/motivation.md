# When starting is the problem

Offer **one** of these, whichever fits the situation best. Don't list them all.

- **Shrink it again.** If the 5-minute version still isn't happening, make a 2-minute version. "Open
  the file" is a legitimate task.
- **Timer with permission to stop.** Starting is the hard part. Promising that stopping is allowed
  lowers the stakes.
- **Body doubling.** Work alongside someone, in person, on a call, or in a co-working stream. In Claude Code
  the user can also narrate progress to Claude every few minutes.
- **Temptation bundling.** Pair the boring task with something enjoyable: a favourite playlist, a good
  coffee, a nice spot.
- **Change the first step's energy.** If they're stuck on a high-energy first step, find a low-energy
  prep step (gather files, open tabs) that makes the real start easier.
- **Name the blocker.** Ask "What's the first thing that feels bad about this?" The answer is usually
  a missing piece of information or a decision. Turn that into a task.
- **Rewards.** Use the ones listed in `.mynotes/profile.md`. Small and immediate beats large and
  distant.
